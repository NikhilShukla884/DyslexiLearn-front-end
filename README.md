# DyslexiLearn-front-end
Final year project(frontend): A platform that is made for true equal opportunities of education for dyslexic and other neurologically challenged students.

Features are: 

->Students Features
Dashboard
Profile (history)
Syllabus
Subject
Attendance #future scope
Progress
Open dyslexic font contents in “to study”
Assessments – Use ML module to predict equivalent English text of the student’s dyslexic handwriting
2 modes →Direct handwriting capturing & Image-based
Voice input/output for the ease of understanding rather than just trying to read
Highlighting keywords & important topics
AI simplification
Helping/assisting with correct spellings, representation with each assessment
Assignments with to improve spelling, representation & understanding
Heatmap of progress
Report errors (contact us)
Feedback

->Teachers Dashboard
Teachers can view progress
Give manual assignments
Check assessment / evaluate
Set assessments
Give notes
Set deadline & other general things
Option to upload notes & test for evaluation

Also note:

To diagnose if there is dyslexia & improvement
